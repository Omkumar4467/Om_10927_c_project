# Menu-Driven Scientific Calculator (C Project)

## 📌 Aim
The aim of this project is to create a menu-driven calculator in C that can compute:
- Square of a number
- Cube of a number
- Power of a number

The program displays a menu, takes user input, performs calculations using basic logic, and shows the result.

---

## 🛠 Features
- Menu-driven interface
- Uses switch-case statements
- Calculates power using loops
- Option to repeat the program
- Beginner-friendly and well-structured

---

## 📋 Steps Followed
1. Included required header files
2. Displayed menu options
3. Accepted user choice using `scanf`
4. Used `switch-case` for selection
5. Calculated square and cube using multiplication
6. Calculated power using a loop
7. Displayed result
8. Allowed program repetition
